# Codna Telys Runtime Artifact Directory

This directory is reserved for release-staged Telys native kernel artifacts.

Only `README.md` and `.gitignore` are committed. The native kernel
`libame_kernel.*` and `manifest.json` are generated by
`scripts/prepare_telys_runtime.py` during release packaging and must not be
committed.

Codna treats staged artifacts as valid only when `manifest.json` exists and the
kernel size and SHA-256 match the manifest. A stray kernel without a manifest is
rejected instead of silently falling back to another runtime source.
